# studio

Next.js приложение автора: видео, загрузки, аналитика, мониторинг канала и заявки
на партнерство.

Приложение отвечает за маршруты и UI студии. Оно использует общие пакеты, но не
импортирует код из `web` или `admin`.

```bash
pnpm nx dev studio
pnpm nx build studio
pnpm nx lint studio
```
