# worker-media-e2e

Резерв под интеграционные сценарии media pipeline через RabbitMQ и S3. HTTP-проверок
здесь нет, поскольку worker не является веб-сервером.

После появления consumer тест должен публиковать команду, дождаться события результата
и проверить артефакты в тестовом bucket. Пока target проходит без тестов.

```bash
pnpm nx e2e worker-media-e2e
```
