# web

Публичное Next.js приложение видеохостинга. Целевые сценарии: каталог, рекомендации,
просмотр видео, профиль, подписки, комментарии, плейлисты, история и загрузка.

Здесь находятся маршруты и composition пользовательского сайта. Общий UI берётся из
`@quakke/ui`, сетевое взаимодействие — из `@quakke/api-client`. Код `studio`, `admin`
и серверная бизнес-логика сюда не импортируются.

Сейчас приложение содержит только стартовый экран.

```bash
pnpm nx dev web --port=3000
pnpm nx lint web
pnpm nx build web
```

TypeScript проверяется внутри `next build`; отдельного Nx target `typecheck` пока нет.
