# web

Публичное Next.js приложение видеохостинга: каталог, рекомендации, просмотр видео,
профиль, подписки, комментарии, плейлисты, история и загрузка.

Здесь находятся маршруты и composition пользовательского сайта. Общие компоненты
берутся из `@quakke/ui`, сетевые запросы - из `@quakke/api-client`. Studio/admin
сценарии и серверная бизнес-логика сюда не входят.

```bash
pnpm nx dev web
pnpm nx build web
pnpm nx lint web
```
