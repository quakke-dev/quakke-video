# admin

Закрытое Next.js приложение для управления пользователями, ролями, жалобами,
модерацией, баннерами, партнерами и аналитикой платформы.

Здесь размещаются только административные маршруты и UI. Авторизация и бизнес-правила
должны проверяться в API, а не только скрываться интерфейсом.

```bash
pnpm nx dev admin
pnpm nx build admin
pnpm nx lint admin
```
