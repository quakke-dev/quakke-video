# admin

Закрытое Next.js приложение для пользователей, ролей, жалоб, модерации, баннеров,
партнёрских заявок и аналитики платформы.

Здесь размещаются только административные маршруты и UI. Авторизация, permissions и
бизнес-правила обязательно проверяются API, а не только интерфейсом.

Сейчас приложение содержит только стартовый экран.

```bash
pnpm nx dev admin --port=3002
pnpm nx lint admin
pnpm nx build admin
```

TypeScript проверяется внутри `next build`; отдельного Nx target `typecheck` пока нет.
