# Local infrastructure

Локальное окружение поднимается единым `docker-compose.yml` из корня.

| Сервис     | Назначение                                   | Порты по умолчанию    |
| ---------- | -------------------------------------------- | --------------------- |
| PostgreSQL | Основная транзакционная база данных          | `5432`                |
| Redis      | Кеш, rate limit, временные данные и счетчики | `6379`                |
| RabbitMQ   | Очереди фоновых задач и событий              | `5672`, UI `15672`    |
| MinIO      | S3-совместимое хранение видео и изображений  | API `9000`, UI `9001` |

## Команды

```bash
cp .env.example .env
pnpm infra:up
pnpm infra:logs
pnpm infra:down
```

Данные сохраняются в Docker volumes. `docker compose down` не удаляет их.
Все порты доступны только на `127.0.0.1`.

Этот MinIO используется только как локальный S3-совместимый стенд: open-source
репозиторий и публичный образ больше не поддерживаются. Production object storage
выбирается отдельным ADR перед деплоем. Nginx и production-конфигурация также
добавляются вместе с первым окружением, когда будут определены домены, TLS и topology.
