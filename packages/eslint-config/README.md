# @quakke/eslint-config

Локальный ESLint flat config семейства Quakke. Содержит базовые TypeScript, React,
Next.js, NestJS и test-настройки без workspace-specific dependency constraints.

Nx tags и правила связей остаются в корневом `eslint.config.mjs`. Это позволит позже
публиковать общий config без привязки к структуре одного репозитория.
