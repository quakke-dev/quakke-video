# @quakke/testing

Общие test builders, fixtures и adapters для unit/integration/e2e. Helpers добавляются
только после реального повторного использования в нескольких проектах.

Пакет не импортируется production-кодом и не содержит бизнес-логику.

Сейчас пакет является пустым foundation skeleton.

```bash
pnpm nx lint testing
pnpm nx typecheck testing
pnpm nx test testing
pnpm nx build testing
```
