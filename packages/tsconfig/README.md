# @quakke/tsconfig

Зарезервированное место для публикуемых TypeScript presets семейства Quakke. Сейчас
не является workspace-пакетом: проект использует корневые `tsconfig.base.json` и
project references Nx.

Пакет стоит создавать только когда появятся минимум два репозитория с одинаковыми
настройками компилятора.
