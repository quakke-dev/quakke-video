# ADR 0001: Modular monolith with workers

- Статус: принято
- Дата: 2026-07-24

## Контекст

Проекту нужны строгие границы и масштабируемые фоновые задачи, но раннее разделение на
микросервисы добавит сетевую и операционную сложность до появления реальной нагрузки.

## Решение

Бизнес-часть реализуется одним модульным NestJS API. Обработка медиа и уведомлений
выносится в отдельные процессы-воркеры. Nx tags и ESLint boundaries контролируют
направление зависимостей.

## Последствия

Разработка и транзакции внутри API остаются простыми. Модули можно выделять в сервисы
только при подтвержденной необходимости. Контракты очередей сразу проектируются как
внешние и версионируемые.
