# ADR 0002: GraphQL and REST responsibilities

- Статус: принято
- Дата: 2026-07-24

## Решение

GraphQL используется для пользовательских и административных бизнес-данных. REST
используется для resumable upload, healthcheck и технических endpoint, где потоковая
передача или инфраструктурные проверки важнее гибкости GraphQL.

## Последствия

Бизнес-операции не дублируются одновременно в GraphQL и REST. Публичные схемы,
ошибки и правила авторизации должны оставаться согласованными на обоих входах.
